    • Hermes + iMessage Setup

    Hermes is a free macOS app that acts as a bridge between your Meshtastic radio and Apple's iMessage. Once running, it lets any iPhone send and receive Meshtastic messages through the standard Messages app — no radio in hand, no Bluetooth pairing required on the phone itself.

    How it works

    A Mac running Hermes stays connected to a Meshtastic radio (via USB or Bluetooth). When a Meshtastic message arrives, Hermes forwards it to a designated iMessage address. When someone replies to that iMessage, Hermes sends the reply out over the mesh. The flow looks like this:

    iPhone (Messages app)
      ↕  iMessage
Mac running Hermes
      ↕  USB / Bluetooth
Meshtastic Radio
      ↕  LoRa RF
Rest of the Okie Mesh network

    The Mac acts as a always-on gateway. It does not need to be near the iPhone — it just needs to be powered on, connected to the radio, and have an internet connection for iMessage delivery.

    Requirements

    • Mac running macOS 13 Ventura or later (Apple Silicon or Intel)
    • Apple ID signed in to iMessage on that Mac (Settings → Apple ID → iMessage)
    • Meshtastic radio connected to the Mac via USB-C/USB serial or Bluetooth
    • Meshtastic firmware 2.3 or later on the radio
    • An iPhone (or any Apple device) you want to use as the remote interface — it just needs the standard Messages app

    Note: Hermes is an open-source community project, not an official Meshtastic product. Check the Hermes GitHub repo for the latest requirements.

    Install Hermes

    1. Download Hermes
      Go to the Hermes Releases page on GitHub and download the latest .dmg file.
    2. Open the DMG
      Double-click the downloaded .dmg, then drag the Hermes app into your /Applications folder.
    3. Allow the app to run
      Because Hermes is not distributed through the Mac App Store you may see a security warning the first time you open it. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to the Hermes entry.
    4. Grant permissions
      Hermes will ask for access to Contacts and Bluetooth. Grant both — Contacts is used to resolve phone numbers, and Bluetooth is needed if you connect your radio wirelessly.

    Configure Hermes

    1. Connect your radio
      Plug your Meshtastic radio into the Mac with a USB cable, or turn on Bluetooth and pair it first via System Settings → Bluetooth.
    2. Open Hermes Preferences
      Launch Hermes, then open Hermes → Settings (⌘,).
    3. Select your radio
      Under Radio Connection, choose USB / Serial or Bluetooth and select your radio from the dropdown. Hermes will show a green indicator once connected.
    4. Set your iMessage relay address
      Under iMessage, enter the Apple ID email address or phone number that Hermes should use to relay messages. This is the address that will appear as the sender on your iPhone. Using a dedicated Apple ID for the relay (rather than your personal one) is recommended so you can tell mesh messages apart at a glance.
    5. Choose which Meshtastic channels to bridge
      In the Channels tab, enable the channels you want forwarded to iMessage. For the Okie Mesh community channel (OkieCorral) enable its slot. You can bridge multiple channels simultaneously.
    6. Save and apply
      Click Save. Hermes will restart its connection and begin relaying messages.

    Pair your iPhone

    There is no separate app to install on your iPhone. Everything goes through the built-in Messages app:

    1. Make sure iMessage is enabled on your iPhone
      Go to Settings → Apps → Messages and confirm iMessage is toggled on.
    2. Add a contact for your Hermes relay
      In Contacts (or directly in Messages), add the Apple ID / phone number you configured in Hermes as a new contact — for example, name it "Okie Mesh Gateway".
    3. Start a new iMessage conversation
      Open Messages, tap the compose button, and send a message to your Hermes relay address. Hermes will forward it to the Meshtastic channel you have mapped for that contact.
    4. Receive mesh replies
      When someone on the mesh replies, Hermes will send you an iMessage and it will appear in the same thread — just like a normal text conversation.

    Using Hermes day-to-day

    Sending a message to the mesh

    Open the "Okie Mesh Gateway" conversation in Messages and type your message. Hermes picks it up and broadcasts it over the radio on the mapped Meshtastic channel. There is typically a short delay (a few seconds) while the radio transmits.

    Receiving mesh messages

    Incoming Meshtastic messages appear as iMessages in the gateway conversation thread. The sender's Meshtastic node name is prepended to each message so you can tell who is talking.

    Direct messages

    If your radio's Hermes instance receives a Meshtastic DM addressed to its node, Hermes can optionally forward it as an iMessage to a specific contact you have configured. Enable this under Settings → Direct Messages.

    Keep Hermes running

    Hermes must stay open on the Mac for the bridge to work. Enable Start at Login in Hermes settings so it launches automatically after a reboot. You may also want to set your Mac's energy settings to Prevent automatic sleeping when the display is off under System Settings → Energy.

    Tips & Troubleshooting

    Hermes shows "Radio not connected"

    • Try unplugging and re-plugging the USB cable.
    • Make sure no other app (Meshtastic desktop, PlatformIO serial monitor, etc.) has the serial port open at the same time.
    • If using Bluetooth, unpair the radio on the Mac and re-pair it.

    Messages arrive on the Mac but not on my iPhone

    • Confirm both devices are signed into the same Apple ID, or that the relay Apple ID is added as a known sender in the iPhone Messages settings.
    • Check Settings → Messages → Send & Receive on your iPhone — the relay address should be listed as a reachable address or it should appear under your Apple ID.

    There is a long delay before messages appear

    • LoRa is inherently slow. At the default "LongFast" spread factor, a short message takes roughly 0.5–2 seconds to transmit; add network hop delays on top of that.
    • If the Mac is on a slow or intermittent internet connection, iMessage delivery can be delayed independently of the radio.

    My messages are not reaching the OkieCorral channel

    • Double-check that the OkieCorral channel is added to your radio. Scan the QR code on the Join page or click here to add it.
    • Verify that Hermes has that channel's slot mapped in Settings → Channels.

    Where to get help

    Join the Okie Mesh Discord and ask in the #hermes channel, or open an issue on the Hermes GitHub repo.
